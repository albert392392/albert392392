## 🛡️ The 5-Point Empirical Verification Gate

Every system I architect is gated by deterministic verification rules:

1. **Proof Mandate:** No completion claims without empirical evidence (exit codes, exact file paths, live HTTP responses, screenshot verifications).
2. **Defensive State:** Mandatory NaN/Infinity validation guards prior to physics/coordinate mutations.
3. **Hot-Loop GC Prevention:** Zero allocations, zero LINQ, and cached shader/property IDs in real-time execution loops.
4. **Resilient Watchdogs:** Universal timeout and stall detectors on audio/vision capture loops to prevent UI lockup.
5. **Fail-Closed Security:** Strict credential isolation, length-only environment validation, and HMAC audit chaining.
