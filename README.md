I am an **AI Systems Engineer & Distributed Architect** specializing in production autonomous agent swarms, sub-second multimodal pipelines (audio/vision loopback), and enterprise microservices.

Over the past years, I have architected and shipped **16+ comprehensive software systems** spanning autonomous agent automation factories, real-time speech translation HUDs, multimodal desktop companions, enterprise fintech platforms, and physics-driven 3D/2D games.

## 🛡️ The 5-Point Empirical Verification Gate

Every system I architect is governed by non-negotiable verification rules:

1. **Empirical Evidence Mandate:** No completion claim without exit code 0, verified file line numbers, live HTTP status codes, and visual proof.
2. **Defensive State Bounds:** Mandatory NaN/Infinity validation guards prior to transform, coordinate, or financial mutations.
3. **Hot-Loop GC Prevention:** Zero allocations, zero LINQ, and pre-cached property IDs in per-frame rendering and audio loops.
4. **Resilient Watchdogs:** Universal timeouts and stall recovery mechanisms on all asynchronous background and speech streams.
5. **Fail-Closed Security:** Strict credential isolation, length-only variable checks, and HMAC-chained audit ledgers.
